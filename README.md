# Pier

Pier превращает сайты в настольные приложения: своё окно, иконка в Dock, меню
и управление с клавиатуры. Сейчас — macOS; Windows следующая, Linux за ней.

Сайт продукта: <https://roman-yerin.github.io/pier/>

## Установка

1. Скачайте [Pier.dmg](https://github.com/roman-yerin/pier/releases/latest/download/Pier.dmg).
2. Перетащите Pier в «Программы» и откройте его один раз.

Pier подписан Developer ID и нотаризован Apple — открывается без
предупреждений. Нужна macOS 14 или новее, Apple Silicon или Intel.

## Как пользоваться

1. Откройте сайт, который поддерживает Pier.
2. Нажмите на нём кнопку установки приложения.
3. Подтвердите установку — Pier соберёт приложение и откроет его с того же
   места, где вы были на сайте.

Приложения лежат в папке «Программы → Pier», их находят Spotlight и Launchpad.
Чтобы удалить приложение, перетащите его в Корзину.

## Для сайтов

Сайту нужен web app manifest. Кнопка на странице открывает ссылку

```
epwa://launch?manifest=<URL манифеста>&handoff=<состояние страницы>
```

Pier загружает манифест, при первом запуске спрашивает разрешения на установку,
собирает приложение и открывает его, передав `handoff` странице. Уже
установленное приложение просто открывается. Внутри приложения странице
доступен `window.epwa` — меню, Dock, фоновый режим, файлы, порты и устройства.

Если Pier ещё не установлен, ссылка `epwa://` ничего не откроет — покажите
пользователю ссылку на [последний релиз](https://github.com/roman-yerin/pier/releases/latest).
